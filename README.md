# Facial-Based Entry System

## Overview
A revolutionary face-recognition-based movie ticketing system, similar to DigiYatra, designed to make your movie-going experience seamless and secure. With this system, your face becomes your ID—no more hassle of carrying tickets or providing contact details!

## Features
- **Face-Based Login:** Say goodbye to traditional logins! No need for email addresses or phone numbers—your face is your key. Simply scan your face and log in instantly.
- **Face as Your Ticket:** No more worrying about carrying movie tickets. Your face acts as your ticket, allowing for smooth entry to movie theaters like PVR and other cinemas.
- **Facial Authentication at Ticketing Booths:** Forget paper tickets or barcodes. Authenticate using your face at the ticketing booth and gain instant access to your movie, making the process faster, secure, and convenient.

## Tech Stack
- **Face Recognition:** OpenCV, dlib
- **Backend:** Flask (Python)
- **Database:** SQLite/PostgreSQL
- **Frontend:** HTML, CSS, JavaScript

## Installation
```sh
git clone https://github.com/rahatbhambri/facial_based_entry.git
cd facial_based_entry
```

## Usage
1. Install dependencies:
   ```sh
   pip install -r requirements.txt
   ```
2. Run the application:
   ```sh
   python app.py
   ```
3. Follow on-screen instructions to register and authenticate using facial recognition.
